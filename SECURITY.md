# Security Policy

## Supported Versions

Only the latest release is supported. Please update before reporting an issue.

## Reporting a Vulnerability

Please report security vulnerabilities privately through
[GitHub Security Advisories](https://github.com/EdoardoTosin/Silly-Redirect-for-Zoom-Meetings/security/advisories/new)
(Security tab > "Report a vulnerability") rather than a public issue.

Include the affected version, browser and version, steps to reproduce, and
the impact you'd expect (e.g. what an attacker could read, modify, or run).

This is a solo-maintained project with no fixed response time. Reports are
read and triaged on a best-effort basis, and a fix or advisory follows once
the issue is confirmed.

## Scope

In scope: the extension code in `src/` and the build/release tooling in
`scripts/` and `.github/workflows/`.

Out of scope: the Zoom web client and desktop app themselves.
